# Persona seed inventory: sources, kinds and seed order

This document answers TASK-343 for the owner and for whoever writes the first records in TASK-348 and TASK-353. It lists the sources under `~/projects/eser` and on the owner's platforms, says which content kind each one becomes (decision-65, doc-4), whether its code stays outside this repository (decision-63), whether it holds sensitive data that must stay out (decision-66), and in which order it is seeded.

The inventory was made on 2026-10-25 from a read-only look at each directory: its file listing, its README, its package manifest and its git remote. No `.env` file, credential file, archive data or note body was opened, so a "sensitive" mark below means the file names or the README point at such data, not that anyone read it. The directory dates are file modification times on disk, which say when something was touched locally, not whether the project is active.

## Seed order

The kind order is settled: approaches, then projects, then bio and experience, then articles and videos. Inside it, the proposed steps are:
